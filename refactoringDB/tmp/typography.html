Design System — Typography

Man in the Loop / info.nodes · All rules extracted from web/base.css, components.css, companysearch.css, index.html, networks.html, search.html · Any new page or component must conform to this system.

01 · Font Families
--font
Barlow Condensed — UI, body, navigation, buttons, labels
'Barlow Condensed', 'Inter', sans-serif
--font-mono
JetBrains Mono — hero titles and animated cursors only
'JetBrains Mono', 'Courier New', monospace
Rule: --font (Barlow Condensed) for all text — prose, UI chrome, badges, IDs, labels, stats. --font-mono (JetBrains Mono) is reserved exclusively for the hero title (.cs-hero-title, .intro-title) and animated cursors (.cs-cursor, .intro-cursor). Never use --font-mono elsewhere. Google Fonts CDN loaded via <link> in every page <head>. Weights used: 400 (regular), 600 (semi-bold), 700 (bold).

16 · Light Theme ("Declassified Document")
Applied via [data-theme="light"] on <html>. All var(--token) usages swap automatically. Warm paper palette: background #f8f7f4, accent #006622 (dark military green). All rgba(0,255,65,…) tints in components must have corresponding [data-theme="light"] overrides using rgba(0,102,34,…).

Light theme init: inline script in <head> before any CSS — if(localStorage.getItem('mitl-theme')==='light') document.documentElement.setAttribute('data-theme','light') — prevents flash of wrong theme. Toggle stored in localStorage['mitl-theme'] via web/theme.js.
17 · Rules & Constraints for New Pages / Components
  1. Always import web/base.css and web/components.css. Never copy-paste their contents inline — single source of truth.
  2. Font loading: include the Google Fonts <link> block in every page <head> (Barlow Condensed 400/600/700 + JetBrains Mono 400/700). Order: preconnect → font link → base.css → components.css.
  3. Never use px for typography except SVG (--fs-svg-*) and Cytoscape canvas labels (8px/9px fixed). All other sizes via var(--fs-*) tokens.
  4. Never go below 13px (~--fs-xs at 120% base). Cytoscape canvas labels exempted (canvas coordinate space).
  5. All text → --font (Barlow Condensed). --font-mono (JetBrains Mono) is reserved exclusively for .cs-hero-title, .intro-title, and their animated cursors. Never use --font-mono elsewhere. Cytoscape canvas labels are exempt (canvas coordinate space).
  6. accent color tints: dark mode uses rgba(0,255,65,…); any such tint needs a [data-theme="light"] override with rgba(0,102,34,…) equivalent opacity.
  7. Uppercase labels: section headers, nav buttons, badge text → text-transform:uppercase; letter-spacing:.4px–2px. Never uppercase body prose.
  8. Entity colors: always use --c-* tokens. Never hardcode entity palette values. Graph libraries (Cytoscape) may use hex literals that mirror these tokens.
  9. Sidebar panels: use --sl-* token stack for all panel typography. Do not define ad-hoc panel font sizes.
  10. Light theme: always include the anti-flash inline script in <head> before CSS. Always include <script src="web/theme.js"></script> and a <button onclick="toggleTheme()"> in topnav.
